# OAIRouter 1.0.2

本次更新修复缓存重复计价、引入 WorkBuddy 会话 ID 分组，并改进统计界面滚动体验。

## Highlights

- **缓存计价修复**：修正 GPT 系列模型缓存写入被重复计为普通输入的问题；未缓存输入公式改为「prompt − 缓存读 − 缓存写」
- **WorkBuddy 对话 ID 分组**：自动从 `X-Conversation-ID` 头读取会话 ID，按完整 ID 分组展示；缺 ID 时统一标为「未识别会话」
- **统计页面滚动**：统计卡片限高并支持内部滚动，切换分组/时间粒度回到顶部，刷新保留滚动位置

## 下载

下载 `OAIRouter-1.0.2-setup.exe`，运行安装向导；推荐选择「仅为我安装」。

完整变更见 [CHANGELOG.md](https://github.com/RexLee0929/OAIRouter/blob/main/CHANGELOG.md)，使用说明见 [README.md](https://github.com/RexLee0929/OAIRouter/blob/main/README.md)。

## 系统要求

Windows 10 / 11（x64），约 80 MB 磁盘空间；.NET 运行时已内置。

## 已知限制

- 服务只监听 `127.0.0.1`，局域网其他设备访问不到。
- 只有 `/chat/completions` 会按模式进行协议翻译或参数改写；其他 JSON 端点也可能替换请求体中的 `model`。
- 模型名映射区分大小写，路由前缀不区分。
- 模型库不从上游拉取，手动维护或用「从用量导入」。
- 价格表匹配不上的请求不计价。
- 缓存计价修正仅针对 GPT 协议总输入包含缓存子类的口径；其他协议的缓存归一化尚未单独验证。
- 「为所有用户安装」时配置与数据写在 Program Files，普通权限可能写不进，推荐「仅为我安装」。
