# OAIRouter 1.0.0

首个公开版本：本机运行的 OpenAI 兼容网关，多上游路由 + Chat Completions ↔ Responses 协议翻译，带用量统计与价格表。

## Highlights

- **协议翻译**：将 Chat Completions 请求转为 Responses，工具调用与流式响应转回客户端格式；上游返回 400 且确认不支持 `reasoning` 时去掉该参数重试一次
- **前缀路由**：通过 `http://127.0.0.1:8787/<前缀>/v1` 的不同前缀访问不同上游
- **用量与金额**：按模型 / 路由 / 会话 / 时间统计 token 与花费；价格表支持分挡、时段、有效期，也能从 new-api / LiteLLM 价格表同步
- **数据与日志**：请求发往配置的上游；用量记录不含对话正文，日志可能含敏感信息，分享前请检查；配置自动备份 10 份

## 下载

下载 `OAIRouter-1.0.0-setup.exe` 运行即可：

- **仅为我安装**（推荐）：`%LOCALAPPDATA%\Programs\OAIRouter`，无需管理员权限
- **为所有用户安装**：请求一次 UAC，装到 `%ProgramFiles%\OAIRouter`

自包含单文件，不需要安装任何运行库。完整变更见 [CHANGELOG.md](https://github.com/RexLee0929/OAIRouter/blob/main/CHANGELOG.md)，使用说明见 [README.md](https://github.com/RexLee0929/OAIRouter/blob/main/README.md)。

## 系统要求

Windows 10 / 11（x64），约 80 MB 磁盘空间；.NET 运行时已内置。

## 已知限制

- 服务只监听 `127.0.0.1`，局域网其他设备访问不到
- 只有 `/chat/completions` 会按模式翻译或改写；首版其他端点的请求体转发存在限制
- 模型名映射区分大小写，路由前缀不区分
- 模型库不从上游拉取，手动维护或「从用量补充」
- 价格表匹配不上的请求不计价
- 「为所有用户安装」时配置与数据写在 Program Files，普通权限可能写不进——推荐「仅为我安装」
