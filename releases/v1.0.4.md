# OAIRouter 1.0.4

本次更新改进用量统计、WorkBuddy 会话关联与模型映射操作。

## Highlights

- **用量统计**：支持模型筛选、别名与实际名称切换，以及上游和时间明细展开。
- **会话关联**：在入站父会话和根请求标识满足匹配条件时，将 WorkBuddy 子任务关联到主请求。
- **界面操作**：模型映射新增置顶、Enter 结束编辑，统计和映射列宽可调整。
- **实验性诊断**：扩充入站关联字段检查，不读取 WorkBuddy 客户端日志。

## 下载

下载 `OAIRouter-1.0.4-setup.exe`，运行安装向导；推荐选择「仅为我安装」。

完整变更见 [CHANGELOG.md](https://github.com/RexLee0929/OAIRouter/blob/main/CHANGELOG.md)，使用说明见 [README.md](https://github.com/RexLee0929/OAIRouter/blob/main/README.md)。

## 系统要求

Windows 10 / 11（x64），约 80 MB 磁盘空间；.NET 运行时已内置。

## 已知限制

- 服务只监听 `127.0.0.1`，局域网其他设备访问不到。
- 只有 `/chat/completions` 会按模式进行协议翻译或参数改写；其他 JSON 端点也可能替换请求体中的 `model`。
- 模型名映射区分大小写，路由前缀不区分。
- 模型库不从上游拉取，手动维护或用「从用量导入」。
- 价格表匹配不上的请求不计价；不同上游协议的缓存 token 口径可能不同，其他协议的缓存归一化尚未单独验证。
- 会话识别依赖客户端提供有效标识；父子关联要求证据匹配，跨进程摘要不互通，旧数据不保证归并；推断关联和请求标识不保证等同于用户对话轮次。
- OpenAI 官方普通 API Key 没有通用余额查询接口；查询能力取决于所配置上游及接口。
- DPAPI 保护的密钥可能无法在其他 Windows 账户或设备解密，迁移后可能需要重新输入。
- 「为所有用户安装」时配置与数据写在 Program Files，普通权限可能写不进，推荐「仅为我安装」。
